## 문서 접근 방법

1. **로컬 접근**: 프로젝트를 클론한 후 `docs` 디렉토리 내 파일 참조
2. **웹 접근**: 오비스 웹 인터페이스 `http://localhost:8080/docs` 에서 접근

## 문서 기여

문서 개선 또는 추가를 원하시는 경우:

1. 해당 마크다운 파일 직접 수정
2. 필요한 경우 새 문서 파일 생성
3. 이 문서 목록 README.md 파일 업데이트
