# 오비스(OVIS) 주제 연관성 스코어링 가이드

## 개요

주제 연관성 스코어링은 뉴스 기사나 콘텐츠가 특정 주제와 얼마나 관련이 있는지 수치화하는 기능입니다. 이 기능은 수집된 데이터를 분석하고 분류하는 데 중요한 역할을 합니다.

## 스코어링 종류

### 1. 정치 성향 분석 스코어링

정치 성향 분석 스코어링은 콘텐츠의 정치적 편향성을 -5(극좌)부터 +5(극우)까지의 척도로 평가합니다.

| 스코어 범위 | 의미 |
|------------|------|
| -5 ~ -3    | 강한 진보 성향 |
| -3 ~ -1    | 진보 성향 |
| -1 ~ +1    | 중립적 |
| +1 ~ +3    | 보수 성향 |
| +3 ~ +5    | 강한 보수 성향 |

### 2. MZ 세대 관심도 스코어링

MZ 세대 관심도 스코어링은 콘텐츠가 MZ 세대(밀레니얼+Z세대)에게 얼마나 관심을 받을 수 있는지를 0부터 10까지의 척도로 평가합니다.

| 스코어 범위 | 의미 |
|------------|------|
| 0 ~ 2      | 매우 낮은 관심도 |
| 3 ~ 4      | 낮은 관심도 |
| 5 ~ 6      | 보통 관심도 |
| 7 ~ 8      | 높은 관심도 |
| 9 ~ 10     | 매우 높은 관심도 |

### 3. 키워드 연관성 스코어링

키워드 연관성 스코어링은 콘텐츠가 특정 키워드와 얼마나 관련이 있는지 0부터 1까지의 척도로 평가합니다.

| 스코어 범위 | 의미 |
|------------|------|
| 0.0 ~ 0.2  | 매우 낮은 연관성 |
| 0.2 ~ 0.4  | 낮은 연관성 |
| 0.4 ~ 0.6  | 보통 연관성 |
| 0.6 ~ 0.8  | 높은 연관성 |
| 0.8 ~ 1.0  | 매우 높은 연관성 |

## 스코어링 활용 방법

### 워크플로우 관리자에서 활용

1. 주제 분석 워크플로우에서 정치 성향 분석 실행 (`8`번)
2. MZ 세대 관심도 분석 실행 (`9`번)
3. 분석 결과를 기반으로 콘텐츠 생성 전략 수립

### API를 통한 활용

다음 API 엔드포인트를 통해 스코어링 결과를 조회할 수 있습니다:

```
GET http://localhost:528/api/agents/alpha/topic-scores/{topic_id}
```

응답 예시:
```json
{
  "topic_id": "t12345",
  "political_bias_score": -1.5,
  "mz_relevance_score": 7.2,
  "keyword_relevance": {
    "디지털": 0.85,
    "기술": 0.78,
    "트렌드": 0.62
  }
}
```

## 스코어링 알고리즘

### 주요 특징

- **다중 소스 분석**: 다양한 출처에서 수집된 정보를 종합적으로 분석
- **문맥 이해**: 단순 키워드 매칭이 아닌 문맥을 이해하는 분석
- **감성 분석**: 텍스트의 감성을 파악하여 정치 성향 분석에 활용
- **트렌드 감지**: 최신 트렌드를 반영한 MZ 세대 관심도 측정

### 기술적 구현

스코어링 알고리즘은 다음과 같은 기술을 활용합니다:

1. 텍스트 임베딩 (Text Embedding)
2. 문서 유사도 측정 (Document Similarity)
3. 감성 분석 (Sentiment Analysis)
4. 주제 모델링 (Topic Modeling)
5. 지도 학습 (Supervised Learning)

## 사용 예시

### 뉴스 분류 작업

1. 다양한 뉴스 소스에서 데이터 수집
2. 각 뉴스에 대한 정치 성향 및 MZ 세대 관심도 스코어링
3. 스코어를 기반으로 뉴스 분류 및 콘텐츠 큐레이션

### 콘텐츠 생성 전략

1. 특정 주제에 대한 스코어링 분석
2. 타겟 독자층에 맞는 콘텐츠 형식 선택
3. 스코어링 결과를 반영한 맞춤형 콘텐츠 생성

## 주의사항

- 스코어링 결과는 절대적인 값이 아니라 상대적인 참고 지표로 활용해야 합니다.
- 알고리즘은 지속적으로 개선되므로 버전에 따라 동일한 콘텐츠에 대한 스코어가 변경될 수 있습니다.
- 문화적, 지역적 맥락에 따라 해석이 달라질 수 있으므로 결과 해석 시 주의가 필요합니다.
